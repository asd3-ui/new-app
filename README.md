# Dungeon Raycast 3D (Multi-Environment & Bilingual)

An advanced 3D raycasting dungeon crawler game featuring multiple distinct environments (Stone Dungeon, Ice Cave, Lava Fortress, Ghost Crypt), multilingual support (Arabic / English), and smooth touch controls for mobile browsers.

## How to Play
1. Upload these files (`index.html`, `style.css`, `game.js`) to your GitHub repository.
2. Enable **GitHub Pages** in your repository settings.
3. Open the generated link and enjoy the game on mobile or desktop!
